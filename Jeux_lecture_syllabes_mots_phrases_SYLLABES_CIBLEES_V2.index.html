Réglages pour les parents

Adapter le jeu à votre enfant

Consonnes à travailler

Cochez les consonnes déjà travaillées avec votre enfant. Ces cases servent uniquement pour les syllabes. Dans les textes à lire, les voyelles sont rouges et les consonnes bleues. Les mots sont en gras. Les syllabes ne sont encadrées que dans les exercices explicitement syllabiques de lecture ou d’assemblage. Les lettres muettes gardent la couleur de leur catégorie ; le y est rouge.

Ajouter vos phrases

Une phrase par ligne. Pour préparer les morceaux du texte, vous pouvez les séparer par / (ex. : Li/na la/ve la ta/ble.). Les couleurs voyelles/consonnes sont appliquées automatiquement. Les ajouts sont utilisés en lecture flash et en remise en ordre.

Aperçu de la taille choisie (agrandie)
Rémi lave la vache.

Quel jeu souhaitez-vous proposer ?

1. Choisissez un jeu.   2. Réglez la séance.   3. Jouez avec votre enfant.

Pour accompagner votre enfant
Laissez-lui le temps de lire. Si besoin, utilisez « Écouter » ou « Voir la réponse ». Dans le jeu de lecture accompagnée, vous validez vous-même sa lecture. Les autres jeux corrigent les réponses choisies à l’écran.

Le bouton « Écouter » utilise les voix installées sur l’appareil. La lecture orale est appréciée par l’adulte : le fichier ne reconnaît pas la voix de l’enfant. Le temps est indicatif.
